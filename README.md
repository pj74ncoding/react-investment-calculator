## Overview

### Motivation

To build a banking application that displays the users investment returns based on the duration and expected returns percentage.

### Learning Outcomes

- learnt how to use chart js and integrate the charts into the existing code
- learnt about clearTimeOut() to remove the setTimeOut() function when the
  calculating results message is displayed
- Learnt to adapt and integrate code into my original code

## Project Features

- Input fields for the user to enter their requirements to be calculated
- A reset button to return the table to the original array
- Buttons to display the investment results in Euros, Dollars or Pounds
- A calculating results message is displayed
- A table to display the investment figures and results over each year of the investment
- A button to display the results in the table by the year or month
- A line chart to display the investment growth over the yearly investment duration
- A bar chart to display the interest growth over the yearly investment duration.

## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/react-investment-calculator.git
cd  react-investment-calculator


```

### Install Dependencies

Frontend:

```bash
cd react-investment-calculator
npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
